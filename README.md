# agent-bot

Telegram-бот персонального Агента на Claude Code. Работает на сервере круглосуточно, отвечает текстом, голосом, принимает фото и документы, ведёт долговременную память в файлах.

Это доработанная версия бота из шаблона [Ntmib/jarvis-architect](https://github.com/Ntmib/jarvis-architect) (MIT). В исходной версии четыре заявленные возможности не работали — все четыре здесь починены или честно убраны.

---

## Что исправлено по сравнению с исходной версией

Каждый пункт найден проверкой вызовов в коде, а не по описанию кнопок.

### 1. Показ действий Агента — был мёртвым кодом

**Как было.** Пока Агент работал, в чат шла крутилка «Думаю… / Соображаю… / Анализирую…» со случайными фразами. Что именно происходит — не видно.

**В чём причина.** Claude Code в потоковом режиме присылает события `tool_use` — каждое действие: какой файл читает, что ищет, какую команду выполняет. Парсер обрабатывал только блоки `text`, а `tool_use` молча выбрасывал. Сам потоковый режим при этом не включался ни разу: функция `callClaude` умела его принимать, но ни один вызов не передавал обработчик.

**Как стало.** Потоковый режим включён, действия распознаются и показываются понятным языком:

```
📖 Читаю MEMORY.md
🔍 Ищу по тексту: воронка продаж
🌐 Ищу в интернете: верификация продавца Paddle
⚙️ Выполняю: проверка структуры проекта

⏳ 23с
```

Видны последние четыре шага и таймер. Работает для текстовых и голосовых сообщений.

### 2. Лимит расходов — ничего не ограничивал

**Как было.** В настройках стояла кнопка «💰 Лимит: $50/день (потрачено: $12.40)». Расход считался честно, но функция проверки лимита вызывалась ровно в одном месте — чтобы нарисовать цветной кружок в `/status`. Достигнув лимита, бот продолжал работать как ни в чём не бывало.

**Как стало.** Лимит реально останавливает работу и предупреждает при 80%. Закрыты все три входа: текстовые сообщения, голосовые и кнопка «Продолжай» — иначе через голос ограничение обходилось.

> **Про сумму.** Цифра берётся из того, что сообщает Claude Code. На подписке Pro/Max реальных списаний за запрос нет, поэтому её правильнее читать как счётчик объёма работы. Лимит всё равно полезен: не даёт Агенту незаметно уйти в бесконечный цикл.

### 3. Кнопка «Режим: Обычный / Авто» — обещала невозможное

**Как было.** Кнопка записывала настройку `state.mode` и показывала описание: «Обычный — Claude спрашивает перед действиями, Авто — Claude действует самостоятельно». Настройка нигде не использовалась.

**Почему не починили, а убрали.** Бот вызывает Claude в неинтерактивном режиме с `--dangerously-skip-permissions`. Спросить разрешение через Telegram ему негде — для этого нужен диалог подтверждения, которого в боте нет. Честно реализовать обещанное нельзя, поэтому кнопка удалена вместе с описанием и строкой в `/status`.

### 4. `/model` отсутствовала в меню

Команда была реализована, но не попала в список команд Telegram: в коде десять команд, в меню девять. Возвращена.

## Что добавлено

### Автоматический выбор модели

Отдельная настройка в `/settings` → «Выбор модели: автоматически». Включена — модель подбирается под задачу:

| Модель | Когда выбирается |
|---|---|
| **Opus** | архитектура, стратегия, исследования, разборы, ТЗ, юридика, риски, монетизация, код — и любая длинная постановка задачи (более 600 символов) |
| **Haiku** | короткие реплики: «спасибо», «ок», «понятно» |
| **Sonnet** | всё остальное |

Какая модель поехала — видно в сообщении о ходе работы. Выключена — работает модель, выбранная руками через `/model`.

Сделано **отдельной** настройкой, а не поверх существующего переключателя «Режим»: тот у автора задуман про автономность действий, и занимать его под модели означало бы снова получить кнопку, которая врёт.

### Безопасное обновление

`update-bot.sh` переписан: проверяет синтаксис **до** замены файлов, делает резервную копию и откатывается автоматически, если бот не поднялся. В исходной версии ни одной из трёх проверок не было.

## Установка на чистый сервер

Нужен VPS с Ubuntu (проверено на 22.04, 24.04 и 26.04), минимум 2 ГБ памяти, и токен бота от [@BotFather](https://t.me/BotFather).

```bash
curl -fsSL https://raw.githubusercontent.com/giftinsideworld-lab/agent-bot/main/install.sh | bash -s -- ВАШ_ТОКЕН_БОТА
```

Скрипт ставит Node.js, Claude Code CLI, VS Code CLI, создаёт пользователя `agent` с рабочими папками, скачивает бота и регистрирует системный сервис. Бота не запускает — сначала нужна авторизация Claude.

### Авторизация Claude

Единственный шаг, который нельзя автоматизировать: интерфейс Claude принимает только живое нажатие клавиши, программно отправленный Enter он игнорирует. Надёжный способ — через `tmux`, он создаёт настоящий терминал:

```bash
sudo -u agent -H tmux new-session -d -s login -x 200 -y 50 claude
sleep 12
sudo -u agent -H tmux send-keys -t login Enter      # тема оформления
sleep 6
sudo -u agent -H tmux send-keys -t login Enter      # способ входа
sleep 6
sudo -u agent -H tmux capture-pane -t login -p | tail -20
```

В выводе появится ссылка `https://claude.com/cai/oauth/...`. Откройте её, нажмите **Authorize**, скопируйте код и отправьте обратно:

```bash
sudo -u agent -H tmux send-keys -t login -l "ВСТАВЬТЕ_КОД"
sudo -u agent -H tmux send-keys -t login Enter
sleep 15
sudo -u agent -H tmux capture-pane -t login -p | tail -5
```

Появилось `Login successful` — готово:

```bash
sudo -u agent -H tmux kill-server
systemctl start agent-bot
```

Напишите боту `/start`. Первый написавший становится владельцем, остальных бот игнорирует.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | меню |
| `/stop` | остановить текущую задачу |
| `/reset` | начать сессию с чистого листа |
| `/settings` | настройки: модель, автовыбор модели, переменные окружения, часовой пояс, лимит, перезагрузка |
| `/status` | версия, модель, часовой пояс, состояние сессии, расход за день |
| `/model` | выбрать модель вручную |
| `/connect` | подключить VS Code через туннель |
| `/reauth` | переподключить Claude |
| `/update` | обновить бота |
| `/version` | версия |

Все кнопки в интерфейсе проверены на реальное действие.
